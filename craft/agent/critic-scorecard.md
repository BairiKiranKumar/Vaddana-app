# Independent Critic: 100-Point Quality Scorecard
**Score is an internal prioritization aid, not a validated measurement of premium quality.** The launch gates below override any total.

| Category | Max | Reviewer asks |
|---|---:|---|
| Brand specificity and central idea | 15 | Could any competitor use it unchanged? Is the idea traceable to real material? |
| Content usefulness and credibility | 15 | Concrete offer, direct language, factual proof, real objections answered? |
| Typography, composition and imagery craft | 15 | Strong hierarchy, purposeful spacing, deliberate crops, consistency? |
| Task flow and conversion clarity | 15 | Clear primary action, short path, trustworthy form/WhatsApp flow? |
| Motion and interaction purpose | 10 | Does motion serve concept, avoid repeats and remain interruptible? |
| Mobile art direction | 10 | Layout intentional, no clipped headlines, no hidden CTA? |
| Accessibility and respect for user control | 10 | Focus, keyboard, pause, reduced motion, semantics, contrast? |
| Real-device speed and resilience | 5 | Field vitals or honest proxy, clean fallback, no blocking loader? |
| Visual system and build integrity | 5 | Tokens, reusable patterns, no regression of approved features? |
| **Total** | **100** |  |

## Shipping classification [Our policy]
- **90–100:** portfolio-ready after blocker review and human approval.
- **80–89:** strong foundation, address largest weaknesses before featuring publicly.
- **70–79:** promising prototype, needs targeted redesign.
- **<70:** return to strategy/art direction before more animation.

## Automatic blockers (NO-GO regardless of total)
- Unverified real-world client facts, invented testimonials or results.
- Broken enquiry / booking / payment / key user journey.
- Essential content invisible with JavaScript off, with low data, or under reduced motion.
- Keyboard trap / obscured focus / inaccessible main CTA.
- Autoplay loop violating relevant pause/stop/hide condition.
- Serious mobile clipping/overlap or browser-crashing WebGL.
- Existing locked layout, asset, API or ERP functionality changed without approval.

## Review response format
```
SCORE: <total>/100, category breakdown
VERDICT: GO | GO AFTER FIXES | NO-GO
EVIDENCE: URLs / screenshots / test environment
BLOCKERS: exact location, repro, impact, fix
TOP 5 REVISIONS: highest business+craft return per hour
WHAT TO REMOVE: unnecessary effects/sections
WHAT TO KEEP: genuinely specific decisions
UNCERTAINTY: what cannot be evaluated from screenshots
RETEST PLAN: device, task, expected result
```
